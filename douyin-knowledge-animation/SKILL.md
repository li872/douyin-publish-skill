# 抖音知识动画（竖屏卡点纯动画）

## 爆款格式公式（对标"曲线求索"）

```
悬念封面(3s) → 9±2 页内容页(每页 3~4s，卡一句歌词) → 末页定格(回味帧)
无解说、无真人；配高扬 DJ 古风热歌（BGM 用户自己在剪映/抖音配，不管）
每页 = 一句大白话金句(punch) + 一个自解释动画，公式只做点缀不做主角
```

## 制作流程

```
Task Progress:
- [ ] 1. 主题拆解：把原理拆成 ≤10 个"金句+画面"分镜
- [ ] 2. 搭单文件 HTML 骨架（720×1280，见 tech-spec.md）
- [ ] 3. 逐页写 Canvas 绘制函数（时间参数 t 驱动）
- [ ] 4. 调 SPD 提速数组：每页高潮画面在 ~2.5s 内出现
- [ ] 5. 内置封面导出：按 C 一键下载 4:3 横版 + 3:4 竖版封面 PNG（见下）
- [ ] 6. 程序化验证（勿依赖截图，见下）
- [ ] 7. 交付 + 告知录屏/剪映踩点流程 + 产出两张封面图文件
```

## 分镜金句写法

- 每页一句 ≤16 字的大白话，禁术语，制造反差："你的等待，是一块算得出面积的三角形"
- 关键词用绿色强调（`<i>` 高亮），句式统一可回扣账号名
- 封面句 = 具体场景 + 悬念："当你等红灯的第 37 秒，交警的电脑在做什么？"
- 末页句 = 升华回扣："你等的每一秒，都是最优解"

## 硬性可读性规范（用户逐条纠正过的，必须遵守）

1. **抖音安全区**：设计稿 720×1280，顶部留 100px、底部留 215px、两侧各留 44px，任何文字/关键动画不得进入（会被导航、文案、点赞栏遮住）
2. **字号**：Canvas 文字统一走一个字体函数并全局放大——`Math.max(16, px*1.3)`，最小 16px；页面小标题 ≥21px 加粗；金句 46px/900
3. **颜色**：正文/刻度/标注一律**纯白 #ffffff**，禁用灰蓝色系（#8593ab 之类手机上看不清）；仅保留绿/红/黄/青做语义强调色；网格线保持暗色
4. **图表**：坐标刻度 ≥15px（放大后 ≥20px），轴标题纯白，柱顶数值 ≥14px
5. **动画自解释**：不懂原理的观众也要能看懂——用状态标注代替术语（如"排队爆了！/绿灯空转/✓ 刚刚好"），结论一句话直给

## 封面图自动生成（每个 HTML 必须内置）

- **每个动画 HTML 必须能自动生成封面图**，两种比例都要：**4:3 横版（1440×1080）+ 3:4 竖版（1080×1440）**
- 交互：按 **C** 键一键渲染并自动下载两张 PNG（文件名：`主题_封面_4x3.png` / `主题_封面_3x4.png`）
- 实现：共用一个 `drawCoverArt(g,w,h)` 绘制函数画到离屏 canvas，`toDataURL('image/png')` + `<a download>` 触发下载；同时挂 `window.renderCover(ratio)` 供程序化验证调用
- **构图必须紧凑、集中在画面中间**：所有标题/图形收进以画面中心为准的 **中央 70% 区域**（横版：宽 70%×高 76%；竖版：宽 84%×高 66%），四周只留氛围底纹，视线焦点全在中间——因为封面在各平台会被不同比例裁切、叠角标，只有中央区域永远安全
- 封面构成 = 大字悬念标题（居中，2 行内）+ 主题图形符号（光环/图标）+ 一行小字副标题；背景延续正片深色氛围底 + 弱化数字雨/纹理（透明度压到 0.2 以下，不抢主体）
- 标题字号按画面短边比例定：短边的 7%~8.5% 每字，加粗 900；横竖两版可共用绘制逻辑，只按 w/h 重排（横版左图右文或纯居中，竖版上图下文）

## 交互规范（录屏友好）

- 无任何控制栏 UI；**鼠标点击或 Enter = 从头自动放映**（重复触发 = 重来）
- F 全屏；←/→ 手动翻页（自动停掉 auto，用于单页检查）
- 封面固定 3s，内容页 pageSec=4s；**末页播完时间冻结定格**（endT 锁帧），绝不循环末页动画
- 录屏流程：F 全屏 → 开录 → Enter → 播完定格 → 停录

## 验证方法（重要教训）

浏览器截图工具在后台标签页会持续超时，**用 evaluate_script 程序化验证**代替：
- 遍历每页：`punch.scrollWidth > clientWidth` 查文字溢出、canvas 尺寸 >2、draw 函数 try/catch 三个时间点无异常
- 后台页 rAF 挂起，测自动放映逻辑要**手动注入时间戳调用 loop(fakeNow)**，不能靠 setTimeout 等待
- 文字宽度用 `ctx.measureText` 对比容器宽，验证放大后不溢出
